ScanRepo GitHub extension

Adds a Scan this repo button to GitHub repository pages. Scans are performed by scanrepo.dev; the extension never downloads or executes repository code.

Anonymous scans hit GitHub's rate limits, which can truncate large repositories and produce an inconclusive result. A token raises those limits for full coverage. It is sent only to scanrepo.dev, never to GitHub pages, and stored in your synced Chrome profile. A token with no scopes is sufficient.

Off by default. When off, the extension asks scanrepo.dev not to add your scan to its public feed. Note that scanrepo.dev may still serve a previously cached public result.

Off by default. When off, scanning only happens when you click the button.

Large repositories can take over a minute on a cold scan.

Limitations

  • Public repositories only — scanrepo.dev cannot scan private repositories.
  • Static analysis only. A safe verdict means no known pattern matched; it is not a guarantee that a repository is safe.
  • Nothing is ever cloned or executed by the extension.
